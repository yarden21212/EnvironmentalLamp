# Environmental Lamp

A small interactive **3D computer graphics project** featuring an articulated desk lamp, lighting controls, camera movement, textures, music, and interactive scene elements.

## About the Project

**Environmental Lamp** was my final project for a Computer Graphics course during my Computer Science degree.

The project demonstrates several fundamental computer graphics concepts, including:

- 3D scene creation
- Texturing
- Lighting
- Projections
- Hierarchical transformations
- Object positioning and movement
- Camera control
- Interactive scene elements

The main object is an articulated desk lamp whose joints can be controlled independently.

## Controls


Once the program starts, **right-click anywhere inside the window** to open the control menu and see the available options.

From the menu, you can:

1. Control the lamp's **upper joint**
2. Control the lamp's **middle joint**
3. Control the lamp's **lower joint**
4. Turn the background music **On / Off**
5. Turn the lamp's light **On / Off**
6. Open and close the **red book**
7. Move and control the **camera**
8. Don't leave the program too quickly, stay a little longer to see the sunset!

Feel free to experiment with the scene and the different controls.
